# Noita Entangled Worlds on Cairn

A fork of [IntQuant/noita_entangled_worlds](https://github.com/IntQuant/noita_entangled_worlds), the multiplayer mod for **Noita**, made to run on the [Cairn launcher](https://github.com/Cairn-client/launcher).

## What we changed

- A Cairn pack: the mod and its proxy are published as a pack the launcher installs and updates, and Play opens the proxy.
- A small program for the launcher that lists and deletes Noita runs and collects its log.

The mod's own code and credits are its authors'. Everything else is as upstream; see [UPSTREAM.md](UPSTREAM.md) for the version this fork is based on.

## Play it

1. Install [Cairn](https://github.com/Cairn-client/launcher/releases/latest).
2. Open Noita in the Library, download the mod and press Play.

Each release of this repository is the pack the launcher downloads.
